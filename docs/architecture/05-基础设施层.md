# 基础设施层 (SmallEBot.Infrastructure)

## 1. 层级职责

基础设施层负责数据持久化：

- **数据库上下文**: EF Core DbContext 配置
- **仓储实现**: `IConversationRepository` 的具体实现
- **数据库迁移**: 版本化的数据库结构变更

**设计原则**: 基础设施层只依赖核心层，实现数据访问接口。

## 3. 仓储实现

### 3.1 ConversationRepository

实现 `IConversationRepository` 接口：

```csharp
public class ConversationRepository : IConversationRepository
{
    private readonly SmallEBotDbContext _context;

    public ConversationRepository(SmallEBotDbContext context)
    {
        _context = context;
    }

    // 会话 CRUD
    public async Task<Conversation> CreateAsync(string userName, string title, CancellationToken ct)
    {
        var conversation = new Conversation
        {
            Id = Guid.NewGuid(),
            UserName = userName,
            Title = title,
            CreatedAt = DateTime.UtcNow,
            UpdatedAt = DateTime.UtcNow
        };
        _context.Conversations.Add(conversation);
        await _context.SaveChangesAsync(ct);
        return conversation;
    }

    // 消息操作
    public async Task<Guid> AddTurnAndUserMessageAsync(...)
    {
        await using var transaction = await _context.Database.BeginTransactionAsync(ct);

        try
        {
            // 1. 创建轮次
            var turn = new ConversationTurn { ... };
            _context.ConversationTurns.Add(turn);

            // 2. 添加用户消息
            var message = new ChatMessage { ... };
            _context.ChatMessages.Add(message);

            // 3. 更新会话标题（首条消息）
            if (newTitle != null)
                conversation.Title = newTitle;

            await _context.SaveChangesAsync(ct);
            await transaction.CommitAsync(ct);

            return turn.Id;
        }
        catch
        {
            await transaction.RollbackAsync(ct);
            throw;
        }
    }

    // 更多方法实现...
}
```

## 4. 数据库迁移

### 4.1 迁移历史

| 迁移 | 描述 | 变更 |
|------|------|------|
| `InitialCreate` | 初始结构 | Conversations, ChatMessages 表 |
| `AddToolCalls` | 工具调用 | ToolCalls 表 |
| `ToolCallToConversation` | 关联调整 | ToolCall 添加 ConversationId |
| `AddThinkBlocks` | 思考块 | ThinkBlocks 表 |
| `AddConversationTurns` | 对话轮次 | ConversationTurns 表，消息关联轮次 |
| `FkNoAction` | 外键行为 | 修改级联删除为 NoAction |
| `AddMessageEditSupport` | 消息编辑 | ChatMessage 添加 IsEdited |
| `AddMessageAttachments` | 附件支持 | Attachments, RequestedSkills 字段 |
| `AddCompressionFields` | 压缩字段 | CompressedContext, CompressedAt |

### 4.2 迁移命令

```bash
# 创建新迁移
dotnet ef migrations add <Name> --project SmallEBot.Infrastructure --startup-project SmallEBot

# 应用迁移
dotnet ef database update --project SmallEBot.Infrastructure --startup-project SmallEBot
```

### 4.3 自动迁移

应用启动时自动应用迁移：

```csharp
// Program.cs
using (var scope = app.Services.CreateScope())
{
    var db = scope.ServiceProvider.GetRequiredService<SmallEBotDbContext>();
    db.Database.Migrate();  // 自动应用所有待处理迁移
}
```

## 6. 实体配置

### 6.1 Conversation 配置

```csharp
modelBuilder.Entity<Conversation>(entity =>
{
    entity.HasKey(e => e.Id);
    entity.Property(e => e.UserName).HasMaxLength(20);
    entity.Property(e => e.Title).HasMaxLength(100);

    entity.HasMany(e => e.Messages)
        .WithOne()
        .HasForeignKey(m => m.ConversationId);

    entity.HasMany(e => e.ToolCalls)
        .WithOne()
        .HasForeignKey(t => t.ConversationId);

    entity.HasMany(e => e.Turns)
        .WithOne()
        .HasForeignKey(t => t.ConversationId);
});
```

### 6.2 ChatMessage 配置

```csharp
modelBuilder.Entity<ChatMessage>(entity =>
{
    entity.HasKey(e => e.Id);
    entity.Property(e => e.Role).HasMaxLength(20);
    entity.Property(e => e.Content).IsRequired();

    // JSON 字段
    entity.Property(e => e.Attachments).HasColumnType("TEXT");
    entity.Property(e => e.RequestedSkills).HasColumnType("TEXT");
});
```

### 6.3 ToolCall 配置

```csharp
modelBuilder.Entity<ToolCall>(entity =>
{
    entity.HasKey(e => e.Id);
    entity.Property(e => e.ToolName).HasMaxLength(100);
    entity.Property(e => e.CallId).HasMaxLength(100);

    // 排序索引
```

## 7. 数据库设计要点

### 7.1 软删除 vs 硬删除

- **硬删除**: 删除会话时级联删除所有关联数据
- **原因**: 本地应用，无需数据恢复

### 7.2 JSON 字段

附件和技能引用存储为 JSON：
- `Attachments`: `["path1", "path2"]`
- `RequestedSkills`: `["skill1", "skill2"]`

### 7.3 索引策略

| 表 | 索引 | 用途 |
|----|------|------|
| Conversations | UserName, CreatedAt | 会话列表查询 |
| ChatMessages | ConversationId, CreatedAt | 消息列表查询 |
| ToolCalls | ConversationId, SortOrder | 工具调用排序 |
| ConversationTurns | ConversationId, CreatedAt | 轮次查询 |

## 8. 性能优化

### 8.1 查询优化

```csharp
// 使用 AsNoTracking 进行只读查询
var conversations = await _context.Conversations
    .AsNoTracking()
    .Where(c => c.UserName == userName)
    .OrderByDescending(c => c.UpdatedAt)
    .ToListAsync(ct);
```

### 8.2 批量操作

```csharp
// 批量删除后续轮次
var turnsToDelete = await _context.ConversationTurns
    .Where(t => t.ConversationId == conversationId && t.CreatedAt > turnCreatedAt)
    .ExecuteDeleteAsync(ct);
```

### 8.3 事务处理

关键操作使用事务确保数据一致性：
- 创建轮次 + 添加消息
- 替换消息 + 删除后续轮次
