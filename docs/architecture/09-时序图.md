# 时序图

## 1. 消息发送完整流程

### 1.1 正常发送消息

```mermaid
sequenceDiagram
    participant User as 用户
    participant UI as ChatArea
    participant State as ChatState
    participant ConvSvc as ConversationService
    participant AgentSvc as AgentConversationService
    participant Repo as ConversationRepository
    participant Runner as AgentRunnerAdapter
    participant Builder as AgentBuilder
    participant Agent as AIAgent
    participant LLM as LLM API
    participant Sink as ChannelStreamSink

    User->>UI: 输入消息并点击发送
    UI->>State: NotifyBeforeSendAsync()
    State->>ConvSvc: CheckAndCompactIfNeededAsync()

    alt 需要压缩
        ConvSvc->>AgentSvc: CompactConversationAsync()
        AgentSvc->>Repo: GetMessagesForConversationAsync()
        AgentSvc->>LLM: 请求生成摘要
        LLM-->>AgentSvc: 摘要内容
        AgentSvc->>Repo: UpdateCompressionAsync()
    end

    UI->>State: StartStreaming()
    State-->>UI: StateChanged

    UI->>ConvSvc: SendMessageAsync()
    ConvSvc->>AgentSvc: CreateTurnAndUserMessageAsync()
    AgentSvc->>Repo: AddTurnAndUserMessageAsync()
    AgentSvc->>Runner: GenerateTitleAsync() (首条消息)
    Repo-->>AgentSvc: turnId

    ConvSvc->>AgentSvc: StreamResponseAndCompleteAsync()
    AgentSvc->>Runner: RunStreamingAsync()

    Runner->>Builder: GetOrCreateAgentAsync()
    Builder->>Builder: 构建系统提示词
    Builder->>Builder: 聚合工具
    Builder-->>Runner: AIAgent

    Runner->>Repo: GetMessagesForConversationAsync()
    Runner->>Runner: 过滤已压缩消息
    Runner->>Runner: 构建 ChatMessage 列表

    Runner->>Agent: RunStreamingAsync()
    Agent->>LLM: 流式请求

    loop 流式响应
        LLM-->>Agent: StreamUpdate
        Agent-->>Runner: TextContent/ThinkContent/ToolCall

        alt 文本内容
            Runner-->>AgentSvc: TextStreamUpdate
        else 思考内容
            Runner-->>AgentSvc: ThinkStreamUpdate
        else 工具调用
            Runner->>Runner: 执行工具
            Runner-->>AgentSvc: ToolCallStreamUpdate
        end

        AgentSvc->>Sink: OnNextAsync()
        Sink-->>UI: 通知更新
        UI->>State: AddStreamUpdate()
        State-->>UI: StateChanged
        UI-->>User: 实时显示
    end

    Agent-->>Runner: 完成
    Runner-->>AgentSvc: 完成
    AgentSvc->>Repo: CompleteTurnWithAssistantAsync()
    AgentSvc-->>ConvSvc: 完成

    ConvSvc->>State: StopStreaming()
    State-->>UI: StateChanged
    UI->>State: SetBubbles()
    UI-->>User: 显示完整回复
```

## 2. Agent 构建流程

### 2.1 首次创建 Agent

```mermaid
sequenceDiagram
    participant Runner as AgentRunnerAdapter
    participant Builder as AgentBuilder
    participant Context as AgentContextFactory
    participant ModelSvc as ModelConfigService
    participant ToolAgg as ToolProviderAggregator
    participant McpMgr as McpConnectionManager
    participant Anthropic as AnthropicClient

    Runner->>Builder: GetOrCreateAgentAsync(useThinking=true)

    Note over Builder: _agent == null，需要创建

    Builder->>Context: BuildSystemPromptAsync()

    Context->>Context: 加载技能列表
    Context->>Context: 加载压缩摘要
    Context-->>Builder: 系统提示词

    Builder->>ModelSvc: GetDefaultAsync()
    ModelSvc-->>Builder: ModelConfig (BaseUrl, Model, ApiKey)

    Builder->>ToolAgg: GetAllToolsAsync()
    ToolAgg->>ToolAgg: 遍历所有 IToolProvider
    ToolAgg-->>Builder: 内置工具数组

    Builder->>McpMgr: GetAllToolsAsync()
    McpMgr->>McpMgr: 遍历所有 MCP 客户端
    McpMgr-->>Builder: MCP 工具数组

    Builder->>Builder: 合并工具列表
    Builder->>Anthropic: new AnthropicClient(options)
    Builder->>Anthropic: AsAIAgent(model, instructions, tools)
    Anthropic-->>Builder: AIAgent

    Builder->>Builder: 缓存 _agent
    Builder-->>Runner: AIAgent
```

## 3. 上下文压缩流程

### 3.1 自动压缩检查

```mermaid
sequenceDiagram
    participant UI as ChatArea
    participant ConvSvc as ConversationService
    participant AgentSvc as AgentConversationService
    participant Estimator as AgentCacheService
    participant Thresh as AgentConfigService
    participant CompSvc as CompressionService
    participant Repo as ConversationRepository
    participant LLM as LLM API

    UI->>ConvSvc: SendMessageAsync()
    ConvSvc->>AgentSvc: CheckAndCompactIfNeededAsync()

    AgentSvc->>Estimator: GetEstimatedContextUsageDetailAsync()

    Estimator->>Repo: GetMessagesForConversationAsync()
    Repo-->>Estimator: 所有消息
    Estimator->>Estimator: 计算当前 Token 数
    Estimator-->>AgentSvc: ContextUsageEstimate

    AgentSvc->>Thresh: GetCompressionThreshold()
    Thresh-->>AgentSvc: 0.8 (80%)

    alt Ratio >= 0.8
        AgentSvc->>AgentSvc: CompactConversationAsync()

        AgentSvc->>Repo: GetByIdNoUserCheckAsync()
        Repo-->>AgentSvc: Conversation (含 CompressedAt)

        AgentSvc->>Repo: GetMessagesForConversationAsync()
        Repo-->>AgentSvc: 所有消息

        AgentSvc->>AgentSvc: 过滤新消息 (CreatedAt > CompressedAt)

        AgentSvc->>CompSvc: GenerateSummaryAsync(messages, toolCalls, existingSummary)

        CompSvc->>CompSvc: 格式化消息内容
        CompSvc->>LLM: 请求生成摘要
        LLM-->>CompSvc: 摘要文本
        CompSvc-->>AgentSvc: 摘要

        AgentSvc->>Repo: UpdateCompressionAsync(summary, DateTime.UtcNow)

        AgentSvc->>AgentSvc: CompressionCompleted 事件
    else Ratio < 0.8
        Note over AgentSvc: 跳过压缩
    end
```

## 4. 命令确认流程

### 4.1 危险命令确认

```mermaid
sequenceDiagram
    participant Agent as AIAgent
    participant Shell as ShellToolProvider
    participant ConfSvc as CommandConfirmationService
    participant Context as CommandConfirmationContext
    participant UI as UI
    participant User as 用户

    Agent->>Shell: ExecuteCommand("rm -rf /")

    Shell->>Shell: 检查命令是否危险

    alt 危险命令
        Shell->>Context: GetCurrentId()
        Context-->>Shell: CircuitId
        Shell->>ConfSvc: WaitForConfirmationAsync(command, circuitId)

        ConfSvc->>ConfSvc: 创建 PendingCommandRequest
        ConfSvc->>UI: ConfirmationRequested 事件

        UI->>UI: 显示确认对话框
        UI->>User: 等待用户操作

        alt 用户允许
            User->>UI: 点击允许
            UI->>ConfSvc: CompleteRequest(Allowed)
        else 用户拒绝
            User->>UI: 点击拒绝
            UI->>ConfSvc: CompleteRequest(Denied)
        end

        ConfSvc-->>Shell: CommandConfirmResult

        alt Allowed
            Shell->>Shell: 执行命令
            Shell-->>Agent: 命令输出
        else Denied
            Shell-->>Agent: "Command denied by user"
        end
    else 普通命令
        Shell->>Shell: 直接执行
        Shell-->>Agent: 命令输出
    end
```

## 5. 消息编辑流程

### 5.1 编辑用户消息并重新生成

```mermaid
sequenceDiagram
    participant User as 用户
    participant UI as ChatArea
    participant ConvSvc as ConversationService
    participant AgentSvc as AgentConversationService

    User->>UI: 点击编辑按钮
    UI->>UI: 显示编辑对话框

    UI->>ConvSvc: ReplaceMessageAndRegenerateAsync()

    Repo->>Repo: 删除后续所有轮次

    ConvSvc->>AgentSvc: StreamResponseAndCompleteAsync()

    Note over AgentSvc: 正常流式响应流程

    AgentSvc-->>ConvSvc: 完成
    ConvSvc-->>UI: 完成
    UI-->>User: 显示新回复
```

## 6. MCP 连接初始化

### 6.1 启动时连接 MCP 服务器

```mermaid
sequenceDiagram
    participant App as Program.cs
    participant Loader as McpToolsLoaderService
    participant McpMgr as McpConnectionManager
    participant Config as McpConfigService
    participant Process as 子进程
    participant Server as MCP Server

    App->>Loader: InitializeAsync()

    Loader->>Config: LoadConfigAsync()
    Config->>Config: 读取 .agents/.mcp.json
    Config-->>Loader: McpConfig

    loop 每个 MCP 服务器
        Loader->>McpMgr: ConnectAsync(name, serverConfig)

        McpMgr->>Process: 启动子进程
        Process->>Server: 启动 MCP 服务器

        Server-->>Process: stdout/stdin 通信
        Process-->>McpMgr: 连接就绪

        McpMgr->>Server: ListTools
        Server-->>McpMgr: 工具列表

        McpMgr->>McpMgr: 缓存工具
    end

    Loader-->>App: 初始化完成
```
